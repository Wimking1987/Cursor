# Website – Stiftung Alterssiedlung Witikon

Projektordner für die Website und Meeting-Unterlagen.

**Live-Entwurf:** https://wimlanz8.wixstudio.com/alterssiedlung

## Dateien

| Datei | Inhalt |
| --- | --- |
| `meeting-checkliste.html` | Kurze Meeting-Checkliste (Änderungen, Freigaben, Deadline) |
| `CHECKLISTE-OEFFNEN.md` | Klickbarer Link zum Öffnen der Checkliste im Browser |

## Checkliste lokal öffnen

Im Ordner:

```bash
python3 -m http.server 8765
```

Dann im Browser: http://127.0.0.1:8765/meeting-checkliste.html

Oder Datei direkt doppelklicken / in Cursor öffnen: `meeting-checkliste.html`
