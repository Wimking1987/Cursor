# Bike Care

Fahrrad-Wartungs-Dashboard: Verschleißteile, manuelle km-Einträge, Monats-Summary, Strava (Demo/API).

UI: dunkles Glassmorphismus-Layout nach Referenzbild.

## Start

```bash
cd bike-care
npm install
npm run dev
```

Details: siehe [PLAN.md](./PLAN.md).

## Env (optional)

```
VITE_STRAVA_CLIENT_ID=
VITE_STRAVA_REDIRECT_URI=http://localhost:5173/
```
